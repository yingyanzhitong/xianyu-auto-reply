# 闲鱼商品主图

制作可直接用于商品列表的高辨识度方形主图。只宣传可从代码、文档或用户描述确认的功能，并保留主图的可读性和可信度。

## 工作流

1. 先读取项目说明、界面文案或用户提供的功能清单，列出可验证卖点。用户提供的竞品截图只能作为视觉节奏参考，不能复制其文字、布局或品牌。
2. 生成新主图时，优先采用 `1:1` 方形 PNG；使用醒目大标题、一个软件窗口或结果示意，以及最多三个短功能标签。保持缩略图下的文字可读。
3. 使用图片生成能力前，加载并遵循 `imagegen` Skill。用 `ads-marketing` 作为用例，并在提示词中明确：资产用途、已验证功能、准确文案、禁用项和参考图角色。
4. 生成后检查标题、价格、功能文案没有错别字或裁切，且没有水印、二维码、联系方式、平台 Logo、虚构数据或未经授权的品牌承诺。
5. 面向项目使用时，把最终稿复制到项目内；不覆盖已有成图，使用递增版本文件名。

## 文案与版式

- 主标题：直接说明核心动作，例如“批量压缩图片”。
- 副标题：说明使用方式或产品形态，例如“桌面版｜拖入即压缩”。
- 功能标签：每项不超过一行，例如“图片 / 文件夹导入”“4 路并发处理”“原图保护”。
- 仅在用户明确给出价格时增加价格贴纸，例如“5元起”。将其放在留白角落，不遮挡标题、软件窗口或功能标签。

禁止把“无损”“永久免费”“秒压”“官方”“最低价”或具体压缩率写入图片，除非用户提供了可核实的授权或事实依据。

## 价格角标编辑

编辑既有主图时，先用 `view_image` 检查本地文件，再使用图片编辑流程。提示词必须重复以下约束：仅新增指定价格文字；其他元素、所有已有文字、色彩、布局和比例均不变；另存为新版本。生成后再次人工检查价格文字是否完全准确。

## 交付

建议使用 `public/marketing/<产品>-xianyu-main-v1.png` 保存首稿，价格版使用 `...-v2-price.png`。用图像工具确认最终文件为方形 PNG 和实际像素尺寸；最终汇报提供可点击文件路径、尺寸、已采用的真实卖点，以及使用的图片生成方式和提示词摘要。
